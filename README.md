### About me

My name is Léo Géré, and I'm a PhD student in Music Information Retrieval.
My thesis explores how musical structure can be leveraged to improve deep learning models for symbolic music.
I investigate this topic in various stages of deep learning pipelines: cleaning data, designing input representations, and constraining models' outputs.
